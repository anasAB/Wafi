## Changes
- **Fix: stale JWT on PowerSync's upload connection after an operator
  switch.** `useOperatorSwitch.ts`'s `switchTo()` called
  `supabase.auth.refreshSession()` after `switch_active_operator`
  succeeded, but never told PowerSync's already-open sync connection to
  pick up the new token. PowerSync kept uploading writes under the stale
  pre-switch JWT (missing/wrong `active_role`), so owner-only writes like
  `denomination_configs` were rejected by RLS server-side even though the
  client's own session looked correct — and any other op batched behind
  it in the same upload (e.g. an `audit_log` write) never got a chance to
  run. Fixed by calling `reconnectPowerSync()` right after
  `refreshSession()`, mirroring the identical fix already in place in
  `useOwnerBootstrap.ts` for the bootstrap case.
- **Fix: TypeScript build errors blocking deploy.**
  - `useReturnSheet.ts`: dropped an unused `cancelledPlanId` destructure
    (TS6133), and fixed `executeFinancialWrite`'s audit callback returning
    `Promise<[void, void]>` instead of `Promise<void>` (TS2322) by
    wrapping the `Promise.all` in an async function body.
  - `LockScreen.vue`: `openingCashUsd`/`openingCashSyp` refs are typed
    `string | number` (Vue's `v-model` auto-casts to `Number` on input),
    but `parseFloat` expects a `string` — wrapped both in `String(...)`
    before parsing (TS2345).
